# The Feud

## A game

Write your own questions and answers with scores.

There are three main components to this app.
First use the editor to build a list of questions and answers.
Then you create a game, in the game you any of your questions, in any order.
You can add the questions to multiple games, if you wish.
Once you are ready to host the game show you start the game and move
to the host control panel where you control which answers are revealed and
which team gets points.
When you start the game you will be given a link this link will take you
to the presentation page for your game.

## How to build a game

### Editor

The game editor is where you will build up your individual games.

A game can can consist of multiple rounds (questions), that you can
build up in any order you wish.

Each question can have up to eight (8) answers that you will have to manually
add the details of.

You can build a permanent list of questions and answers that you can use in
multiple games if you want to host different groups. Then add, as needed, to
your different games.

### Host Controller

The host control panel is where you control the fun! In here you will see the
questions you have assigned to this game. Also you will see the scores of each
team, current round score and strikes given.

Each action will have the automatic sound effects played in the presentation.
However you will also see the sound effects panel, on the bottom of the screen,
where you can play the sound effects any time you like.

### Presentation

Once you load the presentation make sure you click on the page. This is
to ensure the browser allows the sound effects to play.

For full enjoyment set your browswer to full screen, there is a button on the
top right of the page which will set fullscreen mode for your browser. The
button will dim for game play but can still be pressed or use the escape key
to return.
